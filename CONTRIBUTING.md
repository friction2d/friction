# Contribute to Friction

We accept any contributions, big or small. Before submitting a pull request it's recommended that you communicate with the developers first (on [GitHub](https://github.com/friction2d/friction/issues) or [Codeberg](https://codeberg.org/friction/friction/issues)).

It's always preferred to submit pull requests against the `main` branch.

**All contributions must be original work.** Generated code is considered tainted and will not be accepted directly. You may submit generated code drafts to illustrate features or concepts, but a maintainer or contributor must help rewrite the code before it can be merged.

Also, please be honest. Just let us know if your contribution was assisted by AI. We do not shame! We understand that the threshold to contribute to Friction can be high and that not everyone is a developer. If your pull request adds value, we will help you get it merged, either by guiding you through revisions or by doing a complete rewrite. Don't worry: even if we rewrite the code entirely, you will still be credited as a co-author on the commit(s).

However, if you intentionally hide that your code was AI-assisted, or if you communicate with maintainers using an LLM or AI agent, your pull request will be closed and your account may be permanently blocked from this repository.
